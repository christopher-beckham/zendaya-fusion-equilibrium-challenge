# r1: Zara's MAST model, faster training code

r1 is the average of four networks (`rt_ft`, `rt_mix`, `rt_ftw3`, `rt_nonoise`) fine-tuned from one base network
(`h_muon_mo`), by Zara Ercan. This folder holds the code that trains it, with speed-ups that keep Zara's results (see
`SPEEDUP.md`: bit-identical boundary search, fewer CPU-GPU waits, CUDA-graphed equilibrium solve).

| Path | What it is |
|---|---|
| `starter/my_experiments/ch2/syn/fz/` | trains the base network `h_muon_mo` |
| `starter/my_experiments/ch2/g4/fz/` | trains `w3_ft` and the four members |
| `starter/my_experiments/c1/`, `ml/final/capmem.py` | shared helpers; `capmem.py` caps GPU memory at 80 GB and reports the peak |
| `starter/challenge_data` | links to the official data, made by `link_data.sh` |
| `recorded/<run>/args.json`, `hist.json` | Zara's recorded arguments and per-epoch held-out numbers for each of the 6 runs |
| `scripts/train_r1.sh` | trains r1 from scratch (`full`: the six runs) on one GPU from the recorded arguments |
| `scripts/args_to_cli.py` | turns a recorded `args.json` into command-line flags |
| `fetch_r1_data.py`, `r1_data.json` | downloads r1's training data into `R1_ROOT` (pinned revisions, SHA256 per file) |
| `link_data.sh` | points `starter/challenge_data/` (and the one public-test folder the post-processing reads under `R1_ROOT`) at the official data |
| `cpu_caches/` | rebuilds r1's first-pass training caches on the CPU |
| `predict/` | r1's prediction chain on the Final MAST inputs, and the shipped weights' manifest |
| `checks/a2-ultragpu-1g/` | r1's training time on one A100 80 GB (3.65 h) |

## R1_ROOT: Zara's data folder

The code reads its data from one folder, given by the setting `R1_ROOT` (the default, `/fsx/zara.ercan`, is the folder on
our cluster). `fetch_r1_data.py --root $R1_ROOT` fills it:

| Under `R1_ROOT` | What it is | Source |
|---|---|---|
| `cache/ch2/g4/multi/MASTG4*/src`, `cache/m2/multi/MASTSYN/src` | synthetic MAST equilibria (FreeGSNKE, generated by Zara on CPUs from MAST inputs only) | Zara's data bundle `beckhamc/zara-r1-a100-bundle` |
| `cache/nn/diii_d_train`, `cache/pegs/refs_d3d` | official DIII-D training shots as r1 reads them, and their reference targets | same |
| `cache/pegs/machines`, `cache/mast/mast_public_test/basis.npz` | machine matrices and the MAST grid | same |
| `cache/ch2/syn/mastsyn_synth_p7`, `cache/ch2/g4/caches/*`, `cache/pegs/diiid_train_*`, `cache/upegs/aux_d3d_*` | first-pass training caches, built on the CPU | `beckhamc/zara-r1-cpu-caches`, or rebuilt with `cpu_caches/build_r1_caches.sh` |

The bundle also holds Zara's original first-pass caches, which were built on a GPU, and her own trained base model;
`fetch_r1_data.py` does not unpack them. Prediction alone needs only the three small data files that
`predict/fetch_r1.py` downloads with the weights. Every change against Zara's code is marked `# speed-up`, apart from the
`R1_ROOT` setting.
